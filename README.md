# 💼 Banco Java

Sistema bancário simples em Java para praticar programação orientada a objetos, controle de fluxo e manipulação de dados em memória.

## ✅ Funcionalidades

- Depósito em conta
- Saque com taxa
- Transferência entre contas
- Pagamento de contas
- Consulta de saldo
- Exibição de extrato com histórico de transações
- Aplicação de rendimento sobre o saldo
- Uso de limite financeiro
- Menu interativo no terminal

## 🧩 Conceitos aplicados

- Classes e objetos
- Encapsulamento
- Listas em Java
- Controle de fluxo com switch e menus
- Tratamento de entradas do usuário
- Simulação de operações bancárias reais

## 🏗️ Estrutura do projeto

O projeto contém uma única classe principal e outras classes internas para organizar a lógica do sistema:

- `ContaBancaria`: representa a conta do cliente
- `Transacao`: registra cada movimentação da conta
- `Main`: controla o menu de interação com o usuário

## ▶️ Como executar

1. Abra o terminal na pasta do projeto.
2. Compile o arquivo Java:

```bash
javac Main.java
```

3. Execute o programa:

```bash
java Main
```

## 🧪 Exemplo de uso

Ao iniciar, o sistema pergunta:

- nome do titular da conta
- permite realizar operações como:
  - depósito
  - saque
  - transferência
  - pagamento de contas
  - visualização de saldo
  - extrato
  - rendimento

## 🎯 Objetivo

Este projeto foi expandido para simular um sistema bancário mais completo, sendo útil para estudar Java e reforçar conceitos de POO com um cenário realista e prático.
